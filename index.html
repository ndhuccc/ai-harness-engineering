01 — WHAT IS IT

什麼是 AI Harness？

如果 Model 是引擎，Harness 就是車架、煞車、儀表板與導航——讓強大的模型在現實道路上安全前行。

🎛️

編排 Orchestration

把工具、技能、記憶與工作流編成可重現的管線，而非一次性對話。

🛡️

護欄 Guardrails

權限、審批、沙盒與可觀測性，讓自主行為可控、可審計。

🔁

回饋 Feedback

評估、重試、自我修正與人類介入點，形成閉環而非開環。

02 — ARCHITECTURE

典型架構

從 User Intent 到 Side Effect，Harness 在中間承擔所有工程責任。

①

宣告式配置

用 YAML / JSON 宣告模型、工具、約束與記憶，而非散落的 prompt 字串。

②

技能化能力

將可重用流程封裝為 Skill（可發現、可組合、可審計）。

③

可觀測與評估

每一步皆有 trace、每輪皆可 eval，失敗可重現、成功可複製。

03 — WORKFLOW

從 Prompt 到 Production

🧪

1 · Prototype

在 Playground 驗證想法，用最少工具跑通一個端到端案例。

🧱

2 · Harden

抽成 Skill、加上護欄與測試，讓「能跑」變成「每次都能跑」。

🚀

3 · Ship

部署為 Cron / Webhook / Chat Bot，持續觀測並迭代。

「Prompt Engineering 回答 怎麼問；Harness Engineering 回答 怎麼讓它在真實世界穩定交付。」
